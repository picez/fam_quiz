# 38e. Імпорт і експорт вікторин — дизайн

Дата: 2026-11-18. Погоджено власником 2026-11-17: «не лише імпорт, а і експорт», мої пропозиції прийнято. Беклог: `docs/ideas/backlog.md`, «Черга 38».

## Навіщо

Набирати 40 запитань у редакторі з телефона довго. Багатьом зручніше в таблиці. Ще треба мати копію вікторини поза сайтом (резерв, передати іншому автору, перенести між акаунтами).

## Погоджено власником

- **Повний файл вікторини:** усі типи запитань і картинки, в обидва боки.
- **Таблиця Excel / Google Таблиці** для простих типів (варіанти, так/ні, текст, число), в обидва боки.

## Мої рішення (будівничому)

**Повний файл**
- Формат — один файл `.quiz` (zip): `quiz.json` (вміст вікторини + номер версії формату) і папка з медіа (картинки, завантажене аудіо — усе, що лежить у нашому сховищі). Посилання YouTube лишаються посиланнями.
- **Експорт:** у меню вікторини «Експорт → Файл вікторини». Файл названо безпечним ім'ям з назви.
- **Імпорт:** «Мої вікторини → Імпорт» → вибір файлу. Завжди створюється **нова** вікторина в акаунті того, хто імпортує (ніколи не перезаписує наявну). Медіа завантажуються в сховище заново через наявний шлях завантаження з його лімітами.
- Перевірка: вміст проходить ту саму схему, що й збереження з редактора. Файл новішої версії формату — зрозуміла відмова («Файл з новішої версії додатку»). Старіші версії — приймаються, якщо схема дозволяє.
- Ліміт розміру файлу — розумний (будівничий бере з наявних лімітів медіа; орієнтир ≤ 100 МБ).
- Призи (кубки), історія ігор, вподобайки, статистика **не** експортуються — лише сама вікторина.

**Таблиця**
- Формат `.xlsx` (відкривається в Excel і Google Таблицях: «Файл → Завантажити → xlsx» / «Імпортувати»). Імпорт приймає також `.csv` (UTF-8, кома чи крапка з комою). Інтеграції з Google API немає.
- **Колонки:** Раунд · Тип · Запитання · Правильна відповідь · Варіант 1…Варіант 6 · Бали · Таймер (с) · Пояснення.
  - Тип: «варіанти» / «так-ні» / «текст» / «число» (у мові інтерфейсу; імпорт розпізнає назви всіма 7 мовами та англійські ключі).
  - Варіанти: правильна відповідь — текст одного з варіантів (або номер варіанта).
  - Так/ні: «так» / «ні».
  - Текст: кілька прийнятних відповідей через `;`.
  - Число: число (кома чи крапка).
  - Порожні Бали / Таймер — типові значення редактора.
- Рядки з однаковою назвою раунду йдуть в один класичний раунд, у порядку появи.
- **Експорт таблиці:** «Експорт → Таблиця (Excel)». Запитання інших типів пропускаються; після експорту — повідомлення «Пропущено N запитань інших типів (вони є лише у файлі вікторини)».
- **Імпорт таблиці:** спершу перевірка й звіт по рядках («Рядок 5: немає правильної відповіді»). Є помилки — показати список і нічого не створювати; без помилок — нова вікторина (назва з імені файлу) і перехід у редактор.
- **Шаблон:** кнопка «Завантажити шаблон» біля імпорту — `.xlsx` з рядком заголовків і чотирма прикладами (по одному на тип). Зміст прикладів — нейтральний, без жодного російського контексту, таймери ≥ 25 с.
- Заголовки колонок — мовою інтерфейсу; імпорт розпізнає заголовки всіма 7 мовами.
- Ліміт — 500 рядків.

**Загальне**
- Лише з акаунтом (вікторини й так належать акаунтам).
- Розбір файлів — у браузері; створення вікторини — через наявний API збереження (сервер перевіряє схему як завжди). Бібліотеки — легкі, з ліцензіями MIT/Apache (наприклад, fflate для zip; для xlsx будівничий обирає легку бібліотеку з дозвільною ліцензією або власний мінімальний запис/читання). Завантажуються ліниво, лише коли людина відкриває імпорт/експорт.
- Тексти — 7 мов, ключі в ADDED_* (`i18n.test.ts`); довідка автора — короткий розділ про імпорт/експорт (help-uk.ts + golden + *.help.json).

## Обмеження

- `GAME_STATE_VERSION` (22) не змінюється.
- Тести `--maxWorkers=2`, на передньому плані, ніколи два одночасно; без prettier.
- Безпека: імпортований вміст ніколи не довіряється — лише через схему й наявні шляхи завантаження; zip-бомби й зайві файли в архіві ігноруються/обмежуються за розміром; шляхи всередині архіву не використовуються як шляхи файлової системи.
- e2e: експорт → імпорт повного файлу дає ту саму вікторину (з новими адресами медіа); таблиця туди й назад для 4 типів; звіт помилок; 360 px і світла тема.

## Підходи

1. **Розбір у браузері + наявний API** — обрано: сервер майже не змінюється, схема перевіряється як завжди.
2. Окремий серверний ендпоінт імпорту — відкинуто: дублює перевірки, важкі бібліотеки на сервері.
3. Лише CSV — відкинуто: Excel з кирилицею в CSV часто ламає кодування; власник хоче Excel/Google Таблиці.
