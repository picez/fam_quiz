# 45d. «Вгадай слово» без підказок — дизайн

Дата: 2026-11-20. Запит власника: «у вордлі треба без підказок просто поле і вгадати слово». Беклог: «Черга 45».

## Рішення

- Запитання типу `wordle` у грі показує **лише** сітку, клавіатуру й заголовок «Вгадайте слово з N літер» (N — довжина без апострофа). Текст запитання автора не показується ні на телефоні, ні на сцені, ні на пульті під час гри (ведучому — лише слово, як зараз).
- **Редактор:** для `wordle` поле тексту запитання прибране; є лише «Слово». Схема: текст для `wordle` необов'язковий; збережені старі тексти лишаються в даних (нічого не ламається), але не показуються в грі; при збереженні з редактора текст очищається.
- **Бафи-підказки** («Підказка ведучого», «50 на 50» тощо, що показують підказку) у `wordle` вимкнені; поле підказки (`hint`) для `wordle` у редакторі прибране й у грі не показується.
- **Розкриття:** слово великими літерами й сітки — як зараз (без тексту автора).
- **Історія гри / перегляд адміном:** замість тексту — «Вгадай слово: <СЛОВО>».
- **Демо-вікторини:** `wordle`, `school3`, `big1`, `big3` — прибрати тексти-підказки з wordle-запитань; після злиття оновити вікторини на сайті (`--update`).

## Обмеження

- `GAME_STATE_VERSION` (22) не змінюється.
- Тексти — 7 мов; тести `--maxWorkers=2`, на передньому плані; без prettier; робочі файли — лише в `C:\ClaudeCode\quiz`.
- e2e: запитання wordle з текстом у даних — у грі тексту немає, є «Вгадайте слово з N літер»; редактор без поля тексту; телефон 360 px, світла тема; перезапустити наявну частину e2e «Вгадай слово».
