# 44g. Повтор завершеної гри по кроках — дизайн

Дата: 2026-11-20. «Черга 44», погоджено власником; деталі мої.

## Навіщо

Коли хтось скаржиться на нарахування («я ж відповів правильно!»), адмін має побачити, що саме відбулося: хто що відповів, коли, що зарахувала програма чи ведучий, які бафи й дебафи діяли, і як змінювався рахунок.

## Рішення

- В адмінці, у перегляді гри (план 58, адмінський вигляд гри) — кнопка «Повтор по кроках».
- Сторінка повтору: шкала запитань (раунд → запитання), кнопки «Назад / Далі», швидкий перехід до запитання. Для кожного запитання:
  - текст, тип, ціна, правильна відповідь;
  - таблиця гравців (команд): що відповіли (як є, текстом), коли (секунди від початку запитання), зараховано / ні / частково, бали за запитання, рахунок після;
  - події: ручні рішення ведучого («зарахувати», «↶ Бали»), оскарження й результат голосування, бафи/дебафи, що діяли на цьому запитанні, хто вибув/приєднався, пауза.
- Дані — з того, що вже записано про гру (історія, `game.plays`, журнали подій); якщо деяких деталей (наприклад, точного часу відповіді) у старих іграх немає — показати «—», а для нових ігор почати записувати їх (лише додавання полів, без зміни формату збереженого стану гри).
- Лише адміністратори; перегляд записується в журнал.

## Обмеження

- `GAME_STATE_VERSION` (22) не змінюється; міграції — лише додавання.
- Тексти — 7 мов; тести `--maxWorkers=2`, на передньому плані; без prettier; робочі файли — лише в `C:\ClaudeCode\quiz`.
- e2e: зіграти коротку гру (текст, вибір, ручне рішення, оскарження, баф), відкрити повтор, перевірити кроки; телефон 360 px і широкий екран, світла тема.
