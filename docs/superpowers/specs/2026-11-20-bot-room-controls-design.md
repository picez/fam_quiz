# 46a. Кімнати бота: у списку лобі + більше керування з адмінки — дизайн

Дата: 2026-11-20. Запит власника: «коли створюється лобі через бота його не видно в списку лобі, можна доєднатись лише через код. зробити відображення в списку. також дати в адмінці більше можливостей керувати, типу поставити пароль чи видалити гравця чи змінити щось, не лише пауза.»

## Видимість у списку лобі

- Кімната бота (ручний запуск і за розкладом) показується в загальному списку лобі, як звичайна кімната, з ведучим «Квіз-бот» і назвою вікторини.
- Адмін може зробити кімнату прихованою (лише за кодом) — перемикач «Показувати в списку лобі» (типово увімкнено); у плані розкладу — те саме поле.
- Пароль (наявний механізм паролю лобі, 4–32 символи): якщо заданий, кімната в списку з замком, як звичайні кімнати з паролем.

## Керування кімнатою бота з адмінки (вкладка «Бот», картка кімнати)

Усе, що може ведучий звичайної кімнати, крім того, що розкриває відповіді:
- **Лобі:** поставити / змінити / прибрати пароль; показувати чи ні в списку лобі; список гравців з «Вилучити» (наявний `host:kick`, з підтвердженням) і «Відпустити» (наявний `host:release`, якщо доречно); команди — сформувати / перемішати (як у ведучого, якщо вікторина командна).
- **Під час гри:** пауза / продовжити (є), «Пропустити запитання», «+30 с до таймера», «Завершити раунд», «Завершити гру» (є); вилучити гравця.
- Усі дії — через наявні дії ведучого рушія від імені бота, з перевіркою адмін-доступу; у журнал адмінки.
- Адмін не бачить правильних відповідей у цій картці (щоб міг грати сам).

## Обмеження

- `GAME_STATE_VERSION` (22) не змінюється.
- Лише адміністратори; звичайні гравці — без змін.
- Тексти — 7 мов. Тести `--maxWorkers=2`, на передньому плані; без prettier; робочі файли — лише в `C:\ClaudeCode\quiz`.
- e2e: кімната бота видна в списку лобі; пароль — у списку замок, без пароля не зайти; прихована — не видно; вилучити гравця; пропустити запитання й +30 с; телефон 360 px, світла тема.
