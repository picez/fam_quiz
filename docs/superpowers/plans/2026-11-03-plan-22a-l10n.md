# План 22a: Локалізація інтерфейсу — 7 мов, множина, формати, RTL, файли для вичитки (беклог #18)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Мета:** інтерфейс сімома мовами: uk (основна, без змін) + en, pl, de, es, it, ar.
- перемикач у профілі й на сторінці входу;
- вибір зберігається в профілі й у localStorage, а перший раз мова береться з браузера;
- множина й формати через `Intl`, арабська справа наліво;
- довідка ведучого теж перекладена;
- для pl, de, en генеруються файли для вичитки.

**Вміст вікторин не перекладається.**

**Spec:** `docs/superpowers/specs/2026-11-01-localisation-design.md`. Читати повністю: «Що будуємо», «Мої рішення», «Рішення після builder-check», «Не цілі», «Анти-цілі», «Обмеження», «Залишено на будівника».

**Передумова:** у `main` уже все до 21a (адмінка). Міграції до `0027_admin` зайняті, тож наші — **`0028_locale`** (journal idx 28) і **`0029_nickname_null`** (idx 29).

**Стан гри не змінюється: `GAME_STATE_VERSION` лишається 22** (`packages/engine/src/restore.ts`). Сервер не кладе в `GameState` жодного тексту інтерфейсу: помилки йдуть кодами, а цікавинки, ачівки й підписи складає клієнт. Рушій, `GameState`, `SavedRoom` не змінюються. Пуш у `main` не обриває живих ігор.

**Архітектура:**
- **Shared** (`packages/shared/src/locale.ts`): `LOCALES`, `Locale`, схеми, `isRtl`. `PushPayload` має необов'язкове поле `locale`.
- **Сервер:**
  - `profile.locale` (міграція `0028_locale`);
  - `/api/me` віддає ще `locale`, а `PUT /api/me/locale` її зберігає;
  - пуші йдуть мовою профілю одержувача;
  - `profile.nickname` може бути `null` замість «Гравець» (міграція `0029_nickname_null`).
- **Веб:**
  - `apps/web/src/locales/`:
    - `current.ts` — стан мови без словників, придатний для сервіс-воркера;
    - `locales.ts` — увімкнені мови, назви мов, теги `Intl`;
    - `<lang>.json` — UI;
    - `<lang>.help.json` — довідка;
    - `grammar.ts` — граматика, що залежить від мови;
    - `checks.ts` — перевірки повноти;
    - `choose.ts` — виявлення мови, перемикач, синхронізація з профілем;
    - `reviewed/<lang>.json` — що вже вичитано;
  - `i18n.ts`: `t()` / `countText()` / `errorText()` беруть активну мову, а uk-словник лишається тут же, незмінним;
  - довідка ведучого переходить у плоский словник `help/help-uk.ts` з плейсхолдерами;
  - пуш-тексти — `push/strings/<lang>.json`;
  - інструмент `apps/web/scripts/l10n.ts` має команди `todo`, `merge`, `check`, `status`, `sheet`, `apply`.

**Технології:** TypeScript, zod, vitest, Fastify, Drizzle + drizzle-kit + PGlite, React 19 + Vite (динамічний `import()` JSON), Testing Library (jsdom), Playwright, `Intl.PluralRules` / `DateTimeFormat` / `NumberFormat` / `RelativeTimeFormat` / `ListFormat`. Нових залежностей немає: скрипт запускається через `tsx`, який уже є в `apps/server`.

## Рішення (там, де специфікація лишила місце будівникові)

- **Мови:** `LOCALES = ['uk', 'en', 'pl', 'de', 'es', 'it', 'ar']`, саме в такому порядку. Інших немає й не буде; жодної російської, ніде, ні в коді, ні в тестах, ні у фікстурах. Тест у shared перевіряє точну рівність списку.
- **Теги `Intl`** (`INTL_TAGS`):
  - uk → `uk-UA`, en → `en-GB` (24-годинний час, день перед місяцем), pl → `pl-PL`, de → `de-DE`, es → `es-ES`, it → `it-IT`;
  - ar → `ar-u-nu-latn`: цифри західні скрізь (рішення специфікації).
- **Назви мов у перемикачі** — самоназвою, без перекладу (`LOCALE_NAMES`): «Українська», «English», «Polski», «Deutsch», «Español», «Italiano», «العربية». У кожної `<option>` свій `lang`.
- **Структура словників:**
  - uk лишається в `apps/web/src/i18n.ts` (об'єкт `uk`, `as const`, `TextKey` з нього);
  - решта мов — плоскі JSON `apps/web/src/locales/<lang>.json` (UI) і `<lang>.help.json` (довідка). Їх вантажить динамічний `import()`, тож кожна мова — окремий чанк;
  - пуш-тексти не-uk мов — `apps/web/src/push/strings/<lang>.json`, імпортуються статично (сервіс-воркер, 9 ключів на мову);
  - на початку всі 18 JSON порожні (`{}`). Ключі в JSON відсортовані за алфавітом, відступ 2 пробіли, `\n` у кінці (так пише `l10n merge`).
- **Увімкнені мови:** `ENABLED_LOCALES: readonly Locale[]` у `locales/locales.ts`, спочатку `['uk']`. Кожна мовна задача дописує свою мову, коли перевірки зелені. Мова, якої немає в `ENABLED_LOCALES`, не з'являється ні в перемикачі, ні через браузер, ні з профілю.
- **Пріоритет мови:**
  - профіль (для акаунта, якщо мова увімкнена) → localStorage `quiz:locale` → `navigator.languages` (перший, чий основний підтег, як-от `de` з `de-AT`, увімкнений) → `uk`;
  - під час старту `main.tsx` бере localStorage і браузер синхронно, вантажить словник і лише тоді рендерить;
  - профіль приходить з `/api/me` (`useAccount`). Якщо він інший — мова перемикається й пишеться в localStorage;
  - якщо в профілі `null`, а поточна мова не uk, клієнт один раз робить `PUT /api/me/locale` з поточною, щоб пуші прийшли тією мовою, яку людина бачить.
- **Перемикання** — це `chooseLocale(locale)`:
  - вантажить словник, пише localStorage;
  - для акаунта ще робить `PUT /api/me/locale`; збій не відкочує вибору, а показує `languageSaveFailed`;
  - ставить `<html lang dir>` і `document.title = t('appName')`;
  - `LocaleRoot` перемонтовує дерево (`key={locale}`), тож нічого не лишається старою мовою. Перемикач є лише в профілі й на сторінці входу, тож живої гри перемонтування не зачіпає.
- **Тести вебу лишаються українськими:** виявлення мови працює лише в `initLocale()` з `main.tsx`, а тести його не кличуть. Тест, що вмикає іншу мову, повертає `uk` у `afterEach` через `activateLocaleForTests('uk')`.
- **Множина:**
  - `countText(base, count, vars)` бере форму з `new Intl.PluralRules(intlTag()).select(count)`. Ключ — `${base}_${форма}`; немає такого → `${base}_other` → `${base}_many` → uk;
  - для uk `Intl` на цілих дає саме one/few/many, як нинішній код. Тест закріплює наявні значення;
  - **обов'язкові форми** мови — ті, що `select` дає на цілих `0…200`, `1000`, `1000000`, `2000000` (`integerForms(locale)`). Для en і de це one/other; для pl one/few/many; для es та it one/many/other (`many` — мільйони); для ar zero/one/two/few/many/other;
  - дозволені форми — `resolvedOptions().pluralCategories`.
- **Плейсхолдери:**
  - звичайний ключ — та сама множина `{імен}`, що в uk;
  - форма множини — плейсхолдери ⊆ об'єднання плейсхолдерів uk-форм. Арабська «одне запитання» може обійтися без `{count}`.
  - числа в `t()` і далі підставляються `String(value)`: uk не міняється, цифри латинські.
- **Числа в тексті не змінюють сенсу правил** (анти-ціль): набір цифрових послідовностей (`\d+`) перекладу без плейсхолдерів дорівнює набору uk. Для форм множини — підмножина. Винятки — `locales/exceptions.ts`, кожен з причиною в коментарі.
- **Без кирилиці в чужих словниках:** у значеннях en/pl/de/es/it/ar немає `[Ѐ-ӿ]`, у ar немає арабсько-індійських цифр `[٠-٩۰-۹]`. Винятки — там само.
- **Узгодженість термінів:**
  - якщо uk-рядок містить `«X»` і `X` — точне значення UI-ключа K (назва кнопки, раунду, бафу), переклад рядка мусить містити переклад K (без регістру, `toLocaleLowerCase(intlTag)`);
  - перевірка охоплює UI і довідку;
  - ці K і є «глосарій» мови: `l10n todo --glossary` видає їх першими.
- **Довідка ведучого — у словник:**
  - `help/{rounds,questions,cells,powers,settings,teams}.ts` перетворюються на плоский `help/help-uk.ts`;
  - ключі мають вигляд `<prefix>.<key>.<поле>[.<i>]`, наприклад `round.classic.title`, `round.classic.how.0`, `setting.pacing.limits.1`;
  - вирази `${…}` стають плейсхолдерами з `help/help-vars.ts`: `helpVars(locale)` — рядки з констант shared, десяткові числа форматовані мовою (`2,5` uk / `2.5` en). Одиниця пишеться в тексті: `{paceStep} с`;
  - `helpEntry(id)` збирає `HelpEntry` з активного словника довідки. Довжина масивів — за ключами, що є (`how.0…how.n`);
  - вивід uk має бути байт у байт тим самим: golden-фікстура знімається **до** перетворення.
- **Граматика, що залежить від мови** (`locales/grammar.ts`; лише тут і в `i18n.ts`, `help-uk.ts`, `push-strings.ts` дозволена кирилиця в рядках коду):
  - `namesText(names)`: uk — нинішнє «і/й»; решта — `Intl.ListFormat(tag, { type: 'conjunction' })`;
  - `ordinal(n, gender)`: uk — нинішнє «2-а / 3-є»; en — `1st 2nd 3rd 4th 11th 12th 13th 21st 22nd 23rd` (`PluralRules` `type: 'ordinal'`); pl, de — `3.`; es — f `3.ª`, n `3.º`; it — f `3ª`, n `3º`; ar — `3`;
  - `accusativeDay(heading)`: лише uk; решта — без змін;
  - `lowerFirst(label)`: uk, en, pl, es, it — як зараз, локаллю мови; de і ar — без змін (у німецькій іменники з великої);
  - `searchNormalize(s)` довідки — `toLocaleLowerCase(intlTag())`; `compareText(a, b)` — `localeCompare(b, intlTag())`.
- **Час «тому»:** `seenText` бере `Intl.RelativeTimeFormat(tag, { style: 'short' })`. Для uk результат той самий («12 хв тому», «3 год тому»), тож ключі `agoMinutes` і `agoHours` видаляються. Це єдині видалені uk-ключі.
- **Формати:**
  - `formatDate` / `formatDay` / `dayHeading` / `sliderNumber` / `pinDistanceText` / `secondsText` / середнє місце в `StatsView` / `sec()` довідки беруть `intlTag()`;
  - « р.» відрізається лише в uk;
  - `timeText` лишається `HH:mm` руками;
  - дата на дипломі лишається `dd.mm.yyyy` для всіх.
- **Значки-літери:** `TYPE_ICONS.text` ('Аа') і `BUFF_ICONS.letter` ('А…') стають ключами `iconTypeText` / `iconBuffLetter`. uk-значення ті самі, en/pl/de/es/it — 'Aa' / 'A…', ar — 'أب' / 'أ…'.
- **Гендерні форми:**
  - uk лишається як є;
  - en — нейтрально («played»);
  - pl, de, es, it — компактний подвійний варіант як в оригіналі (pl «zagrał(a)», es «jugó» нейтрально, де можна; it «ha giocato» нейтрально);
  - ar — нейтральна форма, де є.
- **Тон:** «ти» — de «du», pl «ty», es «tú», it «tu»; en нейтрально; ar — звертання в однині. Коротко, як в оригіналі.

- **RTL:**
  - `<html dir="rtl" lang="ar">`;
  - напрямні властивості в `styles.css` переходять на логічні (`margin-inline-start`, `padding-inline-end`, `border-inline-start`, `inset-inline-start`, `text-align: start/end`). Фізичне лишається лише з коментарем `/* phys */` у тому ж рядку; тест рахує решту і чекає 0;
  - LTR лишаються:
    - код кімнати (поле й показ);
    - таймер (`.timer`), бали й рахунок (`.score`, клітинки таблиці);
    - повзунок і мапа «точка»;
  - це `dir="ltr"` на елементі, а в CSS — `unicode-bidi: isolate`;
  - вміст авторів має `dir="auto"`: заголовок запитання (`questionClass`), варіанти (`ChoiceFace`), відповіді гравців (`LiveAnswers`, розкриття), назва вікторини (заголовки й списки), ніки (`ScoreTable`, лобі). Рядки, складені з вмісту (`A → B` у `correctText` / `answerText`), лишають «→» і стоять у `dir="auto"`;
  - значки-стрілки інтерфейсу (назад, далі, шеврони) мають клас `flip-rtl`: `[dir='rtl'] .flip-rtl { display: inline-block; transform: scaleX(-1); }`;
  - стрілки всередині перекладених рядків ar перекладач ставить сам: «→» у значенні «далі» стає «←»;
  - `:root:lang(ar)`:
    - `--body` і `--display` = `system-ui, 'Segoe UI', Tahoma, 'Noto Sans Arabic', sans-serif`;
    - `letter-spacing: 0` для всього, бо розрядка рве з'єднання арабських літер.

    Нових шрифтів немає.
- **Нік за замовчуванням:**
  - `DEFAULT_NICKNAME` зникає;
  - якщо ім'я акаунта не проходить `nicknameSchema`, новий профіль має `nickname = null` і `nickname_key = null`. Унікальний індекс пускає багато `null`, тож нумерація «Гравець 2» більше не потрібна;
  - наявні «Гравець…» у базі не чіпаємо;
  - API віддає `nickname: string | null`, а веб показує `nickText(nickname)` → `t('defaultNickname')` = «Гравець»;
  - форма входу в гру з `null` лишає поле порожнім;
  - `admin_label` / `target_label` для `null` = `''`, як зараз для відсутньої людини.
- **Пуші мовою профілю:**
  - `deliver()` читає `profile.locale` одержувачів (left join) і групує підписки за мовою. Тіло = `{ ...payload, locale }`, де `null` → `'uk'`;
  - сервіс-воркер бере тексти `pushStringsFor(payload.locale)`. Невідома чи відсутня мова → uk; пуш не відкидається;
  - `dayHeading` у воркері отримує мову явно.
- **Що бачить кожен:** сцена — мовою браузера чи профілю того, хто її відкрив. Телефон кожного гравця — його мовою. Гість без акаунта — мова з браузера чи localStorage.
- **Що лишається українським:**
  - вміст вікторин, демовікторини власника;
  - `toLocaleLowerCase('uk')` у порівнянні відповідей (рушій);
  - `lang="uk"` у `WallGrid` (переноси вмісту);
  - назва PWA в маніфесті, логи сервера (не для користувача).
- **Файли для вичитки (pl, de, en):**
  - CSV, UTF-8 з BOM, кома, CRLF, лапки за RFC 4180: `docs/l10n/review-pl.csv`, `review-de.csv`, `review-en.csv`. Відкривається в Google Sheets (Файл → Імпорт);
  - колонки: `ключ`, `де в застосунку`, `українською`, `переклад`, `статус`, `виправлення`, `перевірено`:
    - `де в застосунку` — найближчий `// коментар` розділу над ключем у `i18n.ts`; для довідки — «Довідка ведучого: <uk-назва запису> — <поле>»; для пушів — «Сповіщення»;
    - далі `Плейсхолдери: {count} — число…`, якщо вони є;
    - для форм множини — «Форма множини <форма>: напр. 2, 3, 4» (приклади з `integerForms`);
  - форма множини — окремий рядок `<base>_<форма>` мови; в `українською` — усі uk-форми через « / »;
  - **статус:** `чернетка (машинний переклад)`, якщо пари [uk, переклад] немає в `locales/reviewed/<lang>.json`. Інакше `перевірено`. Зміна uk-тексту чи перекладу знову робить рядок чернеткою;
  - клітинка, що починається з `=`, `+`, `-`, `@`, дістає префікс `'`, щоб таблиця не прочитала її як формулу. `apply` знімає один `'`, якщо в uk такого немає;
  - **повернення:** `pnpm l10n apply <lang> <файл.csv>`:
    - непорожнє `виправлення` → новий переклад;
    - непорожнє `виправлення` чи `перевірено` → пара пишеться в `reviewed/<lang>.json`;
    - рядки з невідомим ключем або з плейсхолдерами чи цифрами, що не збігаються, не застосовуються; про них звіт і код виходу 1. Решта пишеться.
- **Хто перекладає:** виконавець мовної задачі (агент) з української, з контекстом. Процес:
  1. `pnpm l10n todo <lang> --glossary`, далі `pnpm l10n todo <lang> --limit 250` (JSON `[{ key, uk, context, forms? }]`);
